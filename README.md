# Omoikane Simple Sales Reports for Welcart

[![CI](https://github.com/omoikane-works/omoikane-simple-sales-reports/actions/workflows/ci.yml/badge.svg)](https://github.com/omoikane-works/omoikane-simple-sales-reports/actions/workflows/ci.yml)

`Omoikane Simple Sales Reports for Welcart` (かんたん売上報告書 for Welcart) は、Welcart の受注データをもとに、売上報告書をかんたんに作成・印刷するための WordPress プラグインです。

## 概要

このプラグインは、Welcart の注文情報から売上報告書を作成し、WordPress 管理画面上で確認・印刷できるようにします。

分析ダッシュボードではなく、月次報告や取引先への提出などに使いやすい、印刷向けのシンプルな報告書作成を目的としています。

## 動作環境

- WordPress 6.6 以上
- PHP 8.2 以上
- Welcart 2.11.10 以上

PHP 8.1 以下の環境では有効化できません。

## 主な機能

- 売上報告書の生成
- 今月・前月・期間指定による集計
- 注文ごとの明細表示
- 税率内訳の表示
- キャンセル注文の集計除外
- A4 横向き印刷を想定した標準テンプレート
- 標準・カスタムテンプレートの選択と、前回の選択の保存
- 標準テンプレートの閲覧・複製、カスタムテンプレートの編集・削除
- ロゴ・社印の登録・差し替え・削除と、テンプレートごとの配置設定

## ロゴ・社印を報告書に表示する

1. WordPress 管理画面の「かんたん報告書」→「売上報告書」→「設定」で、ロゴ・社印を登録します。
2. 「報告書生成」で「標準 売上報告書」の v1.1.0 を選んで「表示」を押すと、登録した画像が集計ページのヘッダーに表示されます。
3. 表示の有無、位置、幅を変える場合は、「テンプレート」で標準テンプレート v1.1.0 を「複製して編集」します。配置はテンプレート内の基準位置からの X・Y 座標と幅を mm 単位で指定します。

画像の登録には PHP の GD 拡張が必要です。登録できるのは静止画の PNG・JPEG・WebP で、上限は 1 MiB、各辺 4,096 ピクセル、総画素数 4,194,304 ピクセルです。

既存のカスタムテンプレートに画像を表示するには、本文に画像タグを追加します。利用できるタグは、編集・閲覧画面の「テンプレート内容」横、または同梱の[テンプレートタグリファレンス](assets/reference.html)で確認できます。

## v1.1.0 へのアップグレード

更新時に標準テンプレート v1.1.0 が追加され、既存のテンプレートと有効な選択は引き継がれます。旧形式の金額や注文者名などのタグも引き続き表示できます。新しいテンプレートでは、テンプレートタグリファレンスに掲載している v1.1.0 のタグ形式を推奨します。

利用・獲得ポイントの数値を表示する旧タグはそのまま使えます。ポイントがゼロかどうかで表示を切り替える場合は、セクションタグに `amounts.used_points.amount` または `amounts.earned_points.amount` を指定してください。末尾に `.amount` がないセクションは、ポイントがゼロでも展開されます。

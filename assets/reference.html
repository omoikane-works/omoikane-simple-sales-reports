テンプレートの基本

テンプレート本文に帳票のHTMLとCSSを書き、表示したい箇所に {{report.title}} などのMustacheタグを置きます。帳票作成時に、タグは対象期間のデータに置き換わります。標準テンプレートをもとに作る場合は、編集画面の［複製して編集］から始められます。

report、store、totals は帳票全体のデータです。orders は注文明細の配列で、ループの中では注文ごとのタグを使います。branding には描画できるロゴ・社印がある場合に画像情報が入ります。

Mustache構文

構文使用例動作
変数{{store.name}}値をHTMLエスケープして出力します。ドットで入れ子のフィールドを参照でき、タグが見つからない場合は空文字になります。
セクション{{#store}}{{name}}{{/store}}データがある場合に囲んだ部分を出力します。オブジェクトの中では、そのフィールドを相対名で参照できます。
真偽値の条件{{#is_sales_counted}}対象{{/is_sales_counted}}注文明細内で対象の注文にだけ表示します。
ループ{{#orders}}{{order_number}}{{/orders}}配列の各要素に対して囲んだ部分を出力します。order_number はその行の注文番号です。
逆セクション{{^orders}}注文なし{{/orders}}値が偽、空の配列、または未定義の場合などに囲んだ部分を出力します。
エスケープなし{{{store.name}}} / {{& store.name}}値をそのまま出力する構文です。帳票の値やHTML属性には通常の {{...}} を使います。

HTML属性に値を入れるときは href="{{store.url}}" のように引用符で囲みます。帳票の集計には下記の集計タグを使います。Mustacheのタグ内で計算式を書くことはできません。

帳票情報

帳票全体で使えます。最上位では {{report.title}}、{{#report}} の中では {{title}} と書けます。

タグ型意味・出力例
report.title文字列帳票タイトル。現在の値は「売上報告書」です。
report.period文字列期間種別。current_month（今月）、previous_month（先月）、custom（期間指定）。
report.start_date文字列対象期間の初日。YYYY-MM-DD 形式（例 2026-10-01）。
report.end_date文字列対象期間の末日。この日を集計に含みます。YYYY-MM-DD 形式（例 2026-10-31）。
report.period_label文字列画面表示用の期間。言語に応じた書式を使います（例 2026年10月1日 ～ 2026年10月31日）。
report.generated_at文字列帳票の出力日時。サイトのタイムゾーンで YYYY/MM/DD HH:mm:ss 形式（例 2026/11/01 10:30:00）。
report.note文字列備考用の予約フィールド。現行版の値は空文字です。

店舗情報

帳票全体で使えます。{{#store}} の中では {{name}}、{{url}} と書けます。

タグ型意味・出力例
store.name文字列WordPressのサイトタイトル（例 青空雑貨店）。
store.url文字列WordPressのサイトアドレス（例 https://shop.example.test）。

集計・金額情報

タグ型意味・出力例
totals.order_count整数対象期間の注文件数。キャンセルを含みます（例 12）。
totals.sales_order_count整数売上集計に含めた注文件数（例 11）。

  • amount は桁区切りのない整数（例 12500）。帳票上の表示には、桁区切り付きの label（例 12,500）が便利です。円やポイントの単位は本文で付けます。
  • 値引きの amount は絶対値です。値引きと利用ポイントの label は控除を示す ▲ 付き（例 ▲500）で、ゼロは 0 になります。
  • お支払合計は、商品合計 ＋ 消費税 ＋ 送料 ＋ 代引手数料 − 値引き − 利用ポイントです。獲得ポイントは控除に含まれません。
  • 税率別の内訳はWelcartの注文に保存された内訳に基づき、該当するデータがない場合は 0 になります。

注文明細

{{#orders}} から {{/orders}} までの間で、次のタグと 注文ごとの金額タグ を使えます。注文は日時の昇順で、同じ日時の場合は注文IDの昇順です。明細にはキャンセルされた注文も含まれます。

orders 内のタグ型意味・出力例
id整数Welcartの注文ID（例 1042）。
order_number文字列帳票表示用の注文番号。注文IDを文字列にしたものです（例 1042）。
order_date文字列注文日。YYYY/MM/DD 形式（例 2026/10/15）。日付を解釈できない場合は空文字です。
order_datetime文字列注文日時。YYYY/MM/DD HH:mm:ss 形式（例 2026/10/15 14:25:00）。日時を解釈できない場合は空文字です。
customer.name文字列顧客氏名（例 空野 はな）。登録されている氏名の各部分を半角スペースでつなぎます。
customer.name_kana文字列顧客氏名のかな（例 ソラノ ハナ）。登録されているかなの各部分を半角スペースでつなぎます。
payment.method文字列注文に保存された支払方法名（例 銀行振込）。
status.raw文字列Welcartに保存されたステータス文字列。複数の値を含むことがあります。
status.label文字列表示用ステータス。キャンセル、新規受付、取り寄せ中、発送済みの順で該当する表示を選びます。対応する表示がない場合は、保存されている値をカンマ区切りで表示します。
is_sales_counted真偽値売上集計の対象かどうか。ステータスに cancel が含まれる注文は false です。セクションで使用できます。
status.is_sales_counted真偽値is_sales_counted と同じ値です。

ロゴ・社印

画像はOSSRの［設定］画面で登録し、表示の有効・無効と配置はテンプレートごとに指定します。配置設定がない場合の既定値は、ロゴ・社印ともに非表示です。表示が無効、画像が未登録、または画像を検証できない場合、その画像のタグは渡りません。片方だけ描画できる場合は、利用できる画像だけが渡ります。

タグ型使用場所・条件
brandingオブジェクト最上位。描画できるロゴか社印が一つでもある場合に {{#branding}} が有効になります。
branding.logoオブジェクト描画できるロゴがある場合に使用できます。{{#branding}} 内では {{#logo}} と書けます。
branding.stampオブジェクト描画できる社印がある場合に使用できます。{{#branding}} 内では {{#stamp}} と書けます。
画像セクション内のタグ型意味・出力例
src文字列検証済み画像のData URI（例 data:image/png;base64,…）。src="{{src}}" と書きます。
x_mm数値基準枠からの水平位置。右が正で、負数・小数も使えます（例 -2.5）。
y_mm数値基準枠からの垂直位置。下が正で、負数・小数も使えます（例 0.5）。
width_mm数値画像の表示幅（例 30）。高さはCSSの height: auto で縦横比を維持します。

画像フィールドは {{#logo}} または {{#stamp}} の内側で使えます。最上位から直接参照する場合は、branding.logo.src や branding.stamp.width_mm のように画像までのパスを書きます。座標が 0 の場合も有効です。表示条件には画像セクションを使ってください。

配置の基準枠

position: relative を指定した要素を基準枠とし、その中に position: absolute の画像を置きます。下の例では、X・Y座標の原点は基準枠の左上です。用紙の左上からの距離は、基準枠自体の位置で変わります。数値タグの直後にCSSの単位 mm を付けます。

<style>
  .report-branding {
    position: relative;
    width: 60mm;
    height: 32mm;
  }
  .report-branding img {
    position: absolute;
    height: auto;
  }
</style>
{{#branding}}
<div class="report-branding">
  {{#logo}}
  <img src="{{src}}" alt="店舗ロゴ"
       style="left: {{x_mm}}mm; top: {{y_mm}}mm; width: {{width_mm}}mm;">
  {{/logo}}
  {{#stamp}}
  <img src="{{src}}" alt="社印"
       style="left: {{x_mm}}mm; top: {{y_mm}}mm; width: {{width_mm}}mm;">
  {{/stamp}}
</div>
{{/branding}}

標準テンプレートv1.1.0は、60 × 32mmの基準枠を集計ページのヘッダーに置き、ロゴをX=0・Y=0・幅30mm、社印をX=38・Y=0・幅18mmに設定しています。注文明細には画像のタグを置いていません。v1.0.0など画像タグを持たないテンプレートで表示するには、本文に画像の記述を追加します。

絶対配置の画像は必要な高さを自動で確保しません。位置や幅によっては表や見出しと重なったり、印刷時に用紙の外へはみ出したりします。印刷プレビューで確認し、実際に使う用紙・向き・倍率でPDFを出力して、切れや重なりがないか最終確認してください。

記述例と印刷確認

店舗名と明細を出力する

<h1>{{report.title}}</h1>
<p>{{report.period_label}} / <a href="{{store.url}}">{{store.name}}</a></p>
<p>売上集計 {{totals.sales_order_count}} 件 / {{totals.amounts.payment_total.label}} 円</p>
<ul>
  {{#orders}}
  <li>
    {{order_number}} {{customer.name}} — {{amounts.payment_total.label}} 円
    {{^is_sales_counted}}（売上集計対象外）{{/is_sales_counted}}
  </li>
  {{/orders}}
  {{^orders}}
  <li>対象期間の注文はありません。</li>
  {{/orders}}
</ul>

出力例は「青空雑貨店」「1042 空野 はな — 12,500 円」です。

編集したテンプレートを保存したら、［帳票作成］でそのテンプレートと対象期間を選んで確認します。注文がない期間と明細が複数ページになる期間の両方を確認すると、空欄表示や改ページを確認できます。画像を集計ページだけに出す場合は、画像セクションを注文明細のループやページヘッダーへ入れず、集計部分に一度だけ置きます。
